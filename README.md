# Context Engineering — Part 7: Evolution

**From Operating System to Evolving Harness.** How a personal agent harness learned to
operate, verify, and evolve itself — on a frozen model.

Four systems you can run in the browser (real logic, no network):
- the voice guard (paste text, get the live AI-writing + voice-law score)
- the preserve-and-extend gate (watch an overfit get rejected)
- the right-oracle check (why absence in the wrong place proves nothing)
- the harness's own manifest-vs-reality drift

Live: https://jtehrani84.github.io/context-engineering-evolution/
